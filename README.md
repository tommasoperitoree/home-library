# Home Library

A Progressive Web App for the family home library (~1100 books). Vanilla
HTML/CSS/JS, no build step, installable on Android and iOS via "Add to Home
Screen".

## Structure

- `index.html`, `css/style.css`, `js/` — the PWA itself
- `manifest.json`, `sw.js`, `icons/` — PWA installability + offline support
- `data/books.json`, `data/loans.json` — bundled fallback data, regenerated by `scripts/sync.py`
- `apps-script/api.gs` — source for the Google Apps Script Web App (version-controlled copy)
- `scripts/sync.py` — downloads the spreadsheet and regenerates `data/*.json`
- `.github/workflows/sync.yml` — runs `sync.py` daily and commits changes

## 1. Deploy the Google Apps Script API

1. Open the family spreadsheet (ID `1HoeEFx_-alYJg6KtL9UUmmDZQZsMwSTY_biIoeSZoUw`) in Google Sheets.
2. Extensions → Apps Script.
3. Paste the contents of `apps-script/api.gs` into the script editor (replace the default `Code.gs`).
4. Deploy → New deployment → type **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
5. Copy the deployment URL (`https://script.google.com/macros/s/XXXX/exec`).
6. Create `js/config.js` (gitignored, never committed) with:
   ```js
   window.APPS_SCRIPT_URL = 'https://script.google.com/macros/s/XXXX/exec';
   ```
   and add `<script src="js/config.js"></script>` before `<script type="module" src="js/app.js">` in `index.html`.
   Alternatively, edit the placeholder constant directly in `js/data.js`.
7. Whenever you change the sheet structure, update `apps-script/api.gs` here too and re-paste it into the script editor — this repo copy is not automatically synced.

## 2. Local development

Serve the folder with any static file server (ES modules require http/https, not `file://`):

```bash
cd home-library
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## 3. GitHub Pages hosting

Push this `home-library/` folder as the repo root (or configure Pages to serve
the `home-library/` subfolder / a `docs/` folder — adjust as needed), then in
repo Settings → Pages, set the source branch/folder.

## 4. Daily data sync (GitHub Action)

`scripts/sync.py` downloads the spreadsheet as `.xlsx` via a Google service
account and regenerates `data/books.json` + `data/loans.json`.

1. Create a Google Cloud service account with read access to Google Drive.
2. Share the spreadsheet with the service account's email address (Viewer access).
3. Download the service account's JSON key.
4. In the GitHub repo: Settings → Secrets and variables → Actions → New repository secret
   - Name: `GOOGLE_SERVICE_ACCOUNT_JSON`
   - Value: the full contents of the JSON key file
5. The workflow in `.github/workflows/sync.yml` runs daily at 02:40 UTC, and can
   also be triggered manually from the Actions tab (`workflow_dispatch`).

To run the sync locally:

```bash
pip install openpyxl google-auth google-api-python-client
export GOOGLE_SERVICE_ACCOUNT_JSON=/path/to/key.json
python3 scripts/sync.py
```

## Data formats

See `js/data.js` for the `MEMBERS` / `SHELVES` constants and `apps-script/api.gs` /
`scripts/sync.py` for how sheet rows map to the compact JSON consumed by the app:

```json
{ "t": "Title", "a": "Author", "l": "Shelf name", "lang": "English", "h": "FamilyMemberName" }
```

```json
{ "id": "L002", "book": "Book title", "lentBy": "Tommi", "borrowedBy": "Friend name", "dateLent": "01/09/2026" }
```
